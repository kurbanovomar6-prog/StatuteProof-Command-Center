# Skill Marketplace Research

## Purpose
Find useful external skill patterns without blindly importing third-party code or turning StatuteProof into a skill collection.

## When to use
Use when asked to research, evaluate, adapt, or add Codex skills for StatuteProof.

## When not to use
Do not use to install broad packs, clone large repositories, or add unrelated skills.

## Required inputs
- Target skill categories.
- Marketplaces to search.
- StatuteProof task or workflow needing support.

## Step-by-step procedure
1. Search skills.sh, skillhub.club, and skillsmp.com.
2. Inspect candidate summary, source repo, commands, scripts, network use, secrets requirements, and license where available.
3. Reject skills requiring external accounts, broad runtime frameworks, unsafe scraping, or vague instructions.
4. Prefer adapting principles into StatuteProof-specific skills instead of copying SKILL.md verbatim.
5. Document attribution and rationale.
6. Add no more skills than the current task requires.

## Output format
- Sources searched.
- Queries used.
- Candidate table.
- Install/adapt/reject decision.
- Safety review.
- Recommended skills, maximum 5-8.

## Safety rules
- No blind installs.
- No dependency installation unless explicitly approved.
- No full third-party repo dumps.
- No secrets or API keys.

## StatuteProof-specific constraints
A skill is useful only if it improves evidence readiness, source monitoring, legal-safe copy, MLRO conversion, project review, or custom source monitoring.

## Example invocation
"Use skill-marketplace-research to find only the best skills for evidence-backed regulatory monitoring."
