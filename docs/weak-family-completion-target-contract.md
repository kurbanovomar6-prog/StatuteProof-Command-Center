# Weak-Family Completion Target Contract

Date: 2026-06-19

## Purpose

This contract defines the non-negotiable target for the remaining weak UAE source families. It prevents the sprint from stopping after one family, adding generic pages, or counting no-save-only rows as monitoring-active.

## Completion Rules

- A family is not done until it has at least 25 monitoring-active sources.
- If a family reaches 25 and more official useful sources are already passing, continue activating them.
- If a family remains below 25, the final report must prove why with tested candidates, blockers, adapter attempts, and exact next technical fix.
- “Could not find sources quickly” is not an acceptable blocker.
- “Generic pages exist” is not an acceptable activation reason.
- No fake source count.

## Monitoring-Active Definition

A source may be enabled and active only when it is official or officially linked, UAE-relevant, public and permitted to monitor, commercially useful, stable, extracted meaningfully, non-duplicate, proof-backed, repeat-baseline-tested, mass-monitor `MONITOR_OK`, source-health acceptable, noise acceptable, and review-gated.

## Current Out-Of-Scope Family

FTA / Tax already reached 25 proof-backed monitoring-active direct official FTA PDF endpoints. FTA is not a new activation target in this sprint.
