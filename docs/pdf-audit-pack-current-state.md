# PDF Audit Pack Current State

Date: 2026-06-16

## Markdown Generation

Markdown is generated in `product/regradar/app/audit_export.py` by `render_audit_pack_markdown(...)`. It includes:

- source name;
- source ID;
- official URL;
- checked timestamp;
- change status;
- source-health status;
- extraction quality;
- proof path;
- diff path;
- normalized hash;
- raw hash;
- linked Acknowledge & Assess record when present;
- legal disclaimer.

## HTML Generation

HTML is generated by `render_audit_pack_html(...)` from the Markdown output. The HTML is the safest source for PDF rendering because it keeps a single audit-pack template path.

## Export Endpoint

`product/regradar/app/api.py` exposes `/api/evidence/export`. It currently accepts an evidence record ID and writes Markdown/HTML only through `write_audit_pack(...)`.

Current response behavior:

- `format: "md_html"`
- `pdf_available: false`
- message says PDF export is not enabled

## Frontend Export Buttons

Current frontend export actions:

- `product/regradar/web/src/components/app/EvidencePage.jsx`
- `product/regradar/web/src/components/app/ReportsPage.jsx`
- `product/regradar/web/src/api.js`

They currently call `evidence.exportAuditPack(evidenceRecordId)` and expect Markdown/HTML output.

## Current Plan / Pricing PDF Status

PDF is currently disabled:

- `product/regradar/app/plan.py`: `pdf_export: False`
- `product/regradar/web/src/data/planCapabilities.js`: `pdfExport: false`
- Pricing/Billing/ChoosePlan copy says Markdown/HTML audit export, not PDF.

## Safest PDF Generation Option

Python Playwright print-to-PDF is the safest option because:

- `playwright==1.60.0` is already in `product/regradar/requirements.txt`;
- `playwright` is importable locally;
- the existing HTML renderer can be reused;
- no new large dependency is needed.

The implementation must not claim PDF success unless an actual `.pdf` file exists on disk.
