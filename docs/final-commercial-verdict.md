# StatuteProof Final Commercial Verdict

Date: 2026-06-16

## 1. Executive Verdict

| Dimension | Score |
| --- | ---: |
| Overall product | 6.8/10 |
| Source pack usefulness | 7.2/10 |
| Parser/monitoring trust | 7.0/10 |
| Evidence/audit trail | 6.8/10 |
| Buyer value | 7.0/10 for matched ICP; 5.5/10 broad market |
| Pricing fairness | 7.0/10 for $199; 5.8/10 for $399 today |
| Demo readiness | 7.5/10 |
| Paid pilot readiness | 7.0/10 |
| $399 UAE Monitor readiness | 6.0/10 |

Bottom line: StatuteProof is commercially interesting and sellable in a controlled pilot. It is not yet a fully mature compliance SaaS. The source pack is useful, but the commercial story must lead with evidence, transparency, and narrow UAE focus, not raw source count.

## 2. What Is Strong

- 62 readiness-supported official UAE sources is real progress.
- Strong CBUAE/AML/payments/open-finance coverage.
- Good DFSA/ADGM/FIU/EOCN/SCA high-value sources.
- Proof/baseline/source-health gating is a real differentiator versus generic website monitors.
- Honest held-source behavior protects trust.
- Legal-safe positioning is mostly disciplined.

## 3. What Is Weak

- CBUAE concentration is too high for a balanced UAE Monitor story.
- VARA and DIFC coverage are not strong enough for those ICPs.
- Acknowledge & Assess is not implemented.
- Frontend still has some sample/mock risk.
- Source maintenance is operationally heavy.
- No enterprise security/workflow posture yet.

## 4. Biggest Risks

1. False confidence.
2. Source maintenance burden.
3. Alert fatigue.
4. CBUAE concentration.
5. Weak VARA/DIFC buyer fit.
6. Hash drift on unstable pages.
7. Sample/live confusion.
8. Missing MLRO review workflow.
9. Solo-founder support burden.
10. Enterprise competitor overcomparison.

## 5. Source Usefulness Verdict

The source pack is valuable, not inflated garbage. About half of the pack is high-value for MLRO/compliance work. The weaker part is not fake, but some CBUAE sub-rulebook/document-list sources are narrow and should not be presented as equal to major regulator endpoints.

Useful claim: "62 readiness-supported sources with visible limitations."

Unsafe claim: "Complete UAE regulatory coverage."

## 6. Competitor Comparison

Enterprise providers crush StatuteProof on breadth, analyst content, integrations, security posture, workflow, and procurement trust. StatuteProof is not comparable to Thomson Reuters, Wolters Kluwer, CUBE, LexisNexis, Ascent, or Regology as an enterprise regulatory-intelligence suite.

Where StatuteProof can win: a narrow, lower-friction, UAE-focused pilot with transparent proof paths, source-health visibility, and founder-led customization.

## 7. Pricing Verdict

- $199: justified for controlled founding pilots.
- $399: partially justified for matched CBUAE/AML/payments buyers; not yet justified as broad self-serve UAE Monitor.
- Enterprise/custom: partially justified only as manual/high-touch consulting-style engagement.

## 8. Would Real Customers Pay?

Yes, but not every buyer.

Most likely to pay now:

- UAE fintech/payment firm.
- Smaller ADGM/DFSA-regulated firm with lean compliance team.
- Compliance consultant serving UAE clients.

Less likely now:

- VARA-only VASP.
- DIFC-heavy firm.
- Large bank.
- Enterprise procurement team.

## 9. Is It Worth The Money?

$199 is worth testing if the buyer currently checks official UAE sources manually and values proof/evidence. $399 can be worth it only when the monitored source scope matches the buyer's obligations and the founder provides high-touch review support.

## 10. What Must Improve Before Scaling Sales?

1. Implement Acknowledge & Assess.
2. Build API-backed source status UI.
3. Add source-health timeline.
4. Improve VARA direct PDF/rulebook extraction.
5. Fix DIFC selectors/access-safe alternatives.
6. Resolve DFSA AML/CTF hash drift.
7. Create 30-day source stability report.
8. Add legal acknowledgement during onboarding.
9. Generate one canonical source-summary artifact.
10. Add demo/live banners across sample-heavy pages.

## 11. What Should We Sell Now?

"Founder-led UAE official-source monitoring pilot for CBUAE/AML/payments-heavy compliance teams. Includes source readiness review, agreed source scope, proof-backed monitoring summaries, visible remediation status, and clear limitations. Monitoring intelligence only. Not legal advice."

## 12. What Should We Not Sell Yet?

- Broad self-serve enterprise compliance platform.
- Legal interpretation or obligation mapping.
- Complete UAE coverage.
- Guaranteed alerting.
- Regulator-certified monitoring.

## 13. Recommended Public Claims

- "66 enabled UAE official-source endpoints."
- "62 readiness-supported after proof, baseline, source-health, noise, and review gates."
- "4 sources remain under extraction remediation."
- "Monitoring intelligence only. Not legal advice."
- "Source health and remediation status are shown transparently."

## 14. Forbidden Claims

- "60 validated sources."
- "Complete UAE compliance coverage."
- "Perfect parsing."
- "Never miss updates."
- "Guaranteed compliance."
- "Legal advice."
- "Regulator certified."

## 15. Next Exact Product Task

Implement Acknowledge & Assess MVP for saved evidence records only: data model, API endpoints, UI action, Markdown export, and tests proving no-save previews cannot create review records.

## 16. Next Exact Sales Task

Recruit 5 narrow-fit pilot prospects: UAE fintech/payment firms or compliance consultants with CBUAE/AML monitoring pain. Sell a $199 founder-led pilot, not broad self-serve software.

## 17. Brutally Honest Final Answer

If I were advising the founder, I would say: you finally have something real enough to test with paid pilots, but not something broad enough to sell aggressively as a mature compliance platform. The source count is no longer fake, but the source mix is uneven and the workflow is unfinished. Sell the narrow proof-backed monitoring pilot now, keep the claims humble, and build Acknowledge & Assess before pushing $399 as the default product.
